# Suburb content workflow

The target suburb list in `suburb-page-data.csv` came from the business owner. It supports a grouped service-area page, with each booking still confirmed for the customer's address and site setup.

Create a standalone suburb page only when the row contains checked, useful local evidence such as a genuine local job, an accurately described vehicle/service, a customer question that is genuinely asked, or confirmed availability/travel conditions. Get permission before using job photos or customer-identifying details. Leave missing facts blank. Do not fill gaps by swapping suburb names in generic copy.

The five review-backed pages currently use local customer feedback already displayed on Shelby's public website. Their job photos were not supplied, so each example is clearly described without implying an illustrative photo is that job.

Pricing and package inclusions are stored in `service-packages.json`, checked against the public Shelby homepage on 20 November 2026. Update this source first, then sync the homepage and local pages after business confirmation. Do not use the old studio address or imply customer-facing premises.
